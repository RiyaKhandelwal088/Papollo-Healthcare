# Papollo-Healthcare-Dashboard

1. Project Title / Headline  
   Hospital Operations & Patient Analytics Dashboard — Papollo Hospital

2. Short Description   
   An interactive healthcare analytics dashboard designed to monitor hospital operations, patient flow, and financial performance. It provides insights into bed occupancy, diagnosis trends, billing vs insurance coverage, and patient feedback. Users can track admission, discharge, and follow-up timelines through dynamic filters. The dashboard converts hospital data into actionable insights for operational and clinical decision-making. 

3. Tech Stack  
  • 📊 Power BI Desktop – Main data visualization platform used for report creation.  
  • 📂 Power Query – Data transformation and cleaning layer for reshaping and preparing the data.   
  • 📝 Data Modeling – Relationships established among tables (resorts, snow, and data_dictionary) to enable cross-filtering and                 aggregation.  
  • 📁 File Format – .pbix for development and .png for dashboard previews.     
   
4. Key Features of the Dashboard  
   • 🏥 Operational Overview — Displays admit date, discharge date, follow-up schedule, and total billing amount.  
   • 🛏️ Bed Occupancy Analysis — Visual comparison of Private, General, and ICU utilization.  
   • 🧬 Diagnosis-Wise Patient Distribution — Identifies most common medical conditions and patient volume.  
   • 💰 Billing vs Insurance Comparison — Tracks financial coverage and revenue patterns across diagnoses.  
   • ⭐ Patient Feedback Insights — Aggregated satisfaction scores for service evaluation.  
   • 📅 Dynamic Date Range Filtering — Enables time-based analysis of hospital workflow.  
   • 👤 Patient-Level Filtering — Drill-down capability for detailed record analysis.  
   • 📊 Executive-Ready Visualization — Clean layout for quick clinical and administrative insights.
